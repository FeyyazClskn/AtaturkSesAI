# API Key Kurulumu

1. Fish Audio hesabınıza giriş yapın.
2. Dashboard → API Keys bölümünü açın.
3. Create New Key ile kendi API anahtarınızı oluşturun.
4. Atatürk TTS'yi açın.
5. AYARLAR → Fish Audio API anahtarı alanına anahtarı yapıştırın.
6. KAYDET.

API key'i GitHub'a, Discord'a, ekran görüntüsüne veya kaynak koda koymayın.

Anahtar sızarsa Fish Audio'dan iptal edip yenisini oluşturun.

Yerel ayar dosyaları:

Linux:
`~/.config/ataturk-tts/settings.json`

Windows:
`%USERPROFILE%\.config\ataturk-tts\settings.json`

Resmî Fish Audio Quick Start:
https://docs.fish.audio/developer-guide/getting-started/quickstart
